# Icon with Text Block Documentation

## Overview
The Icon with Text block allows you to display an icon alongside text with various customization options. This block is perfect for creating feature lists, contact information, or any content that benefits from visual icons paired with text.

## Features
- Upload custom icons or use SVG icons
- Editable text with customizable font size and color
- Two layout options: inline or stacked
- Icon position control (before or after text)
- Adjustable icon size
- Spacing control between icon and text
- Vertical alignment options for inline layout
- Optional link wrapping with target control
- Color settings for both icon and text

## How to Use

### Adding the Block
1. In the WordPress editor, click the "+" button to add a new block
2. Search for "Icon with Text" or find it under the "Murdeni Blocks" category
3. Click on the Icon with Text block to add it to your page or post

### Basic Configuration
1. **Upload an Icon**: Click the "Upload Icon" button in the block toolbar or sidebar
2. **Edit Text**: Click on the text area to modify the content
3. **Set Layout**: Choose between "Inline" or "Stack" layout in the sidebar settings

### Advanced Options

#### Icon Settings
- **Icon Size**: Adjust the size of the icon using the range slider
- **Icon Position**: Choose whether the icon appears before or after the text
- **Icon Color**: Set a custom color for the icon

#### Text Settings
- **Font Size**: Adjust the size of the text using the range slider
- **Text Color**: Set a custom color for the text

#### Layout Settings
- **Layout**: Choose between "Inline" (icon and text side by side) or "Stack" (icon above text)
- **Vertical Alignment**: For inline layout, align the icon and text to top, center, or bottom
- **Spacing**: Control the space between the icon and text

#### Link Settings
- **Add Link**: Click the link button in the toolbar to add a URL
- **Open in New Tab**: Toggle whether the link should open in a new browser tab

## Examples

### Contact Information
Use the Icon with Text block with phone, email, or location icons paired with the corresponding contact information.

### Feature List
Create a list of features or services, each with its own distinctive icon.

### Call to Action
Combine an attention-grabbing icon with compelling text and a link to create a call to action.

## Tips
- For best visual results, use icons with consistent styling
- When using the inline layout, adjust the vertical alignment to ensure proper alignment between the icon and text
- For mobile responsiveness, the stack layout often works better on smaller screens
- Use the block alignment options (left, center, right) to position the entire block within your content

## Troubleshooting
- If the icon doesn't appear, ensure you've successfully uploaded an image
- If styles aren't applying correctly, try refreshing the page or rebuilding the plugin assets
- For any other issues, check the browser console for JavaScript errors
